GRID-TO-CHIP PORTFOLIO
grid-to-chip-calculator python · engineering calculator

Walks an AI data center's electrical load down through every voltage tier — utility feed, MV distribution, facility transformer, PDU/busway, rack whip — and sizes conductors and breakers at each stage using real three-phase current formulas and NEC-style continuous-duty derating. The same sizing problem as a connector/harness spec, applied to hyperscaler scale.

InputGPU count, TDP, PUE, redundancy
OutputAmperage & breaker size per tier
Tests9 passing unit tests
